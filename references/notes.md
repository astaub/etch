# wireframe references

## Core framing

- Karpathy-style "agent-native" iteration: agent-readable outputs should be
  immediately usable by another human or agent without render tools.
- Marty Cagan: product shape first, then mechanics — map outcomes before visuals.
- Weights & Biases on experiment loops: compare alternatives on a small shared
  evidence axis and one decision metric.

## Practical constraints

- Use ASCII first, always.
- Use copy-pasteable markdown artifacts; no binary outputs.
- Keep alternatives in one ordered block, cheapest to most expensive.
